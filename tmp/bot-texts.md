# Тексты для BotFather

Открыть [@BotFather](https://t.me/BotFather) → `/mybots` → `@tiddewatchbot` → **Edit Bot**.
Ниже — что куда вставить. Картинки лежат рядом: `tmp/bot-welcome.png` и `tmp/bot-avatar.png`.

---

## 1. Edit Description

Это текст на пустом экране до нажатия «Начать» — под ним же показывается
Welcome Picture. Лимит 512 символов.

```
Крипта и акции США в одном месте. 100 монет и 72 акции, цены в реальном времени, свой портфель и разбор рынка человеческим языком.

Поставь на сайте алерт на цену — он придёт сюда, даже когда браузер закрыт: цену сверяет сервер, а не открытая вкладка.

Бесплатно и без регистрации.
```

## 2. Set Welcome Picture

Загрузить файл `tmp/bot-welcome.png` (640×360).

## 3. Edit About

Короткая строка в профиле бота. Лимит 120 символов.

```
Дежурный по рынкам: крипта и акции США, свой портфель и алерты о цене прямо в чат
```

## 4. Edit Commands

Список команд для меню рядом с полем ввода. Вставить целиком:

```
market - что сейчас с рынком
top - кто растёт, а кто падает
coin - цена и разбор монеты: /coin btc
stock - цена акции США: /stock nvda
alerts - оповещения о цене сюда, в чат
channel - канал с новостями
help - справка
```

## 5. Edit Botpic

Уже сделано, файл был `tmp/bot-avatar.png`.

---

Тексты внутри самого бота (`/start`, `/help`, `/alerts`) живут в коде,
в `api/tg.js`, и обновляются деплоем — их в BotFather вставлять не нужно.
